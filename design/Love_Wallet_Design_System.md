# Love Wallet App Design System

## Design Concept
Airbnb Emotion + Stripe Finance + Pinterest Memories

## Core Style
- Warm
- Romantic
- Soft
- Modern
- Premium
- Minimal
- Trustworthy

## Main Color
```css
--primary: #FF385C;
--soft-pink: #FFF1F3;
--cream-white: #FFFBFA;
--text-dark: #1F1F1F;
--text-gray: #707070;
--border: #EFEFEF;
--success: #22C55E;
--warning: #F59E0B;
--error: #EF4444;
```

## Typography
```css
font-family: Inter, SF Pro Display, sans-serif;
```

## Border Radius
```css
--radius-card: 24px;
--radius-button: 16px;
--radius-input: 14px;
```

## Mobile-First Design Rules
- Portrait layout only
- Bottom navigation optimized for thumb reach
- Large touch targets
- Soft spacing
- One-hand usability
- iOS + Android friendly
- Emotional finance UX
- Airbnb + Stripe inspired

## Do
- Use soft colors
- Use large rounded cards
- Make finance feel emotional
- Add couple memories
- Use warm microcopy

## Don't
- Don't make it look like crypto app
- Don't use cold corporate banking UI
- Don't overuse charts
- Don't use aggressive dark colors
- Don't make screens overcrowded

## Final Vision
Love Wallet is not only a finance app.

It is a digital home where two people save money, build memories, and grow together.
